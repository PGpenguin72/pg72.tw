![拯救 Mococo 題目](./assets/mococo6.jpeg)

接下來是最後的第三關，文件我們找到後看到下面有一串奇怪的符號，我一開始猜測是 Unicode ，但最後得到說他是 Winding，然後箱子是出題者告訴我們的（因為時間不多了），反正箱子在工作人員的那間326，然後我們看到了箱子，他不是密碼，而是鑰匙？  
我們在看了很久最後的提示文件後（因為最後的 winding 解出來是一個程式碼分別是指 
```cpp
for (int i;;++i）{cout << arr[i][ii%44]}
for (int i;;++i）{cout << arr[i][(i+1)(i+2)%44]} 
```
我在想，題目就沒有定義 arr 而且也沒給任何有用的，我們又再次看了一次題目後，我看到了一個敘述：「或許這份指令與另一份資料相互配合能搞出一些東西」，然後我又想為什麼要取模44，我說：「會取模44代表有什麼東西他的限制就是44…..」  
這時我看著上面的文字，越看越奇怪，我數了一下，沃草！一行44個字！對上了！！！！！   
我把i 帶入裡面，得到了位置，0,0、1,4…… 我去對照整份表！發現出現了「賴宇宏」（出題者）的名字！
我們就一起解一起算，最後得到了這句話：「兇手如賴宇宏，是面對他說『還我狗勾』，他會給你東西。」，但由於我數數有問題，差了一點，是最後在出題者引導+淳講才拿到鑰匙，這時競賽只剩下不到2分鐘，我們先拿紙條後，我們趕快衝回去教室，但教室是被鎖著的，我們就在外面敲門拍門喊「開門！開門！」（超級好笑www），然後開門後我的隊友就把程式寫上去提交了解答!

# 心得  
這次活動其實很硬，每天都是課程和競賽。我還記得工人有說：「這次的營隊，聽不懂很正常，這裡面的很多東西，都是大學花了一個學期才會學到的東西。」把大學一學期的課程壓縮成四天要聽懂......至少我沒有這麼厲害啦，甚至有幾堂還在睡覺www 但我認為我還是學到了一些解題方式，例如 Nim、圖論...etc.

還有，我覺得我還有一個收穫「人脈」，在課程的時候我記得有提到類似說你如果要打競賽，你就去看圈子中有哪些人比你利害，程度在哪裡，要怎麼超過他。我覺得這次認識了 Swoda 大佬、235、北電創始人之一 Cheng...etc，這群都是很厲害的佬啊！

總而言之，如果你對程式競賽有興趣，一定要報這個營隊體驗看看！
